# 备份历史和通知优化功能设计

## [S1] 问题描述

用户在使用网盘同步时遇到问题：被查盗版后文件自动同步到云盘，撤销同步需要逐个点击。需要：
1. 备份历史界面：查看监控期间的自动备份记录，支持撤销备份
2. 通知优化：避免每个备份都单独弹窗，使用浮动通知合并显示

## [S2] 解决方案概览

### 2.1 备份历史标签页
- 位置：主窗口添加"备份历史"标签页
- 时间范围：最近3天记录
- 状态验证：自动检查备份文件是否存在、是否有更新版本
- 功能：支持撤销备份（删除本次备份版本）

### 2.2 浮动通知组件
- 自定义浮动窗口，位置在屏幕右下角
- 显示"某某文件完成备份"，持续2秒
- 2秒内有新备份则累加显示，无新备份则自动消失
- 不播放声音

### 2.3 右键菜单功能
- 所有文件列表支持右键菜单
- 跳转到源文件所在目录
- 跳转到备份文件所在目录

## [S4] 备份历史标签页设计

### 4.1 界面布局

```
┌─────────────────────────────────────────────────┐
│ [备份历史] [日志]                                │
├─────────────────────────────────────────────────┤
│ 时间范围: [最近3天 ▼]  状态: [全部 ▼]  [刷新]  │
├─────────────────────────────────────────────────┤
│ □ 时间       文件名      大小   状态   [撤销]   │
│ □ 14:30     项目1.GCL   2.3MB  有效   [撤销]   │
│ □ 14:28     项目2.GCL   1.1MB  已失效 [撤销]   │

│ [全选] [取消全选] [批量撤销]  已选 0/共 15 条   │
└─────────────────────────────────────────────────┘
```

### 4.2 功能说明

**筛选功能：**
- 时间范围：最近3天/今天/全部
- 状态筛选：全部/有效/已失效
- 刷新按钮：重新加载数据

**状态验证逻辑：**
- 有效：备份文件存在 且 是该文件的最新版本
- 已失效：备份文件不存在 或 有更新的备份版本

**撤销功能：**
- 单条撤销：点击每行的"撤销"按钮
- 批量撤销：选中多条记录后点击"批量撤销"
- 撤销操作：删除该次备份的 .7z 文件

## [S5] 浮动通知组件设计

### 5.1 界面样式

```
┌────────────────────────────────────┐
│ ✓ 项目1.GCL 完成备份              │
│ ✓ 项目2.GCL 完成备份              │
│ ✓ 项目3.GCL 完成备份              │
└────────────────────────────────────┘
```

### 5.2 行为逻辑

**显示规则：**
- 位置：屏幕右下角，任务栏上方
- 内容：文件名 + "完成备份"
- 持续时间：2秒
- 累加逻辑：2秒内有新备份则累加显示，重置计时器
- 最大显示：5条记录，超出时滚动显示

**技术实现：**
- 使用 QWidget 实现浮动窗口
- 使用 QTimer 控制显示时间
- 使用 QPropertyAnimation 实现淡入淡出效果

### 5.3 与现有通知的对比

| 特性 | 现有通知 | 新浮动通知 |
|------|----------|------------|
| 位置 | 系统托盘气泡 | 屏幕右下角浮动窗口 |
| 声音 | 有 | 无 |
| 合并 | 5秒内相同消息不重复 | 2秒内累加显示 |
| 自动消失 | 3秒 | 2秒无操作后消失 |
| 可交互 | 否 | 否 |

### 6.2 实现方式

创建通用的右键菜单工具函数：

```python
def create_file_context_menu(widget, source_path, backup_path):
    """为文件列表创建右键菜单"""
    menu = QMenu(widget)
    menu.addAction("打开源文件所在目录", lambda: open_folder(source_path))
    menu.addAction("打开备份文件所在目录", lambda: open_folder(backup_path))
    return menu

def open_folder(path):
    """打开文件所在的文件夹"""
    import subprocess
    subprocess.Popen(f'explorer /select,"{path}"')
```
